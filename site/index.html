Cantus — a Claude-first coding environment for macOS

The IDE around Claude Code — Monaco editor, an integrated terminal running the Claude CLI, and per-line git staging in one native window. Not a bolted-on sidebar.

Download for macOS View on GitHub

macOS (Apple Silicon) · local-first & private · unsigned build — right-click → Open on first launch

One app, in concert

Editor, terminal, git, and Claude Code sharing one UI and one project.

🖥️

Claude Code in a real terminal

The claude CLI runs in a backend-spawned PTY — full-width, themed, and resumable. This is the actual Claude Code CLI, not a chat wrapper.

📎

Drag files into Claude

Drop any file onto the terminal to insert its path straight into the prompt.

🔍

VS Code-style diff

Split and inline views with per-hunk and per-line stage & discard, powered by libgit2 patches — not a read-only viewer.

🌿

Built-in git

Branch switcher, stage, commit, and discard — via libgit2, no shelling out.

💾

Resumable sessions

Your Claude Code sessions for the project, listed and resumable from the chat pane.

⚙️

Capability-aware task runner

Describe a task; Claude summarizes which skills & agents apply, builds a .claude workflow, and runs it — orchestrating itself.

🧠

Learned memory

A local SQLite + FTS5 memory distills the quirks each run teaches and surfaces the relevant ones on the next — no cloud, no vectors.

🔒

Local-first & private

Your source never leaves the machine except Claude's own model calls.

Composed, not reinvented

Cantus wraps mature, battle-tested components — and builds only the glue and the genuinely novel parts.
