## ✨ Core features

Cantus provides a focused environment for coding. You do not need to hunt through dozens of menus or windows. All your tools sit in one place.

### The editor
The interface centers on a professional text editor. This editor highlights syntax to make your code easy to read. It provides suggestions as you type, which helps reduce errors. You can open multiple files at once by using the sidebar file browser.

### The terminal
A built-in terminal runs at the bottom of the window. You use this to run commands, check for errors, and talk to your software. Because the terminal connects directly to the coding environment, you spend less time switching between apps.

### AI assistance
Cantus integrates with advanced language models to assist with your tasks. You can ask for help with complex logic or find bugs in your code. The app remembers your previous sessions, so you can pick up a task exactly where you left off yesterday.

### Git support
Managing your versions is simple. You can view changes, add lines to your commits, and save your progress with a few clicks. The tool provides a visual representation of your changes, so you see exactly what you modify.

### Local memory
The application stores your work and search history in a local database on your hard drive. This local memory ensures the system becomes more helpful the longer you use it, without sending your private project data to third-party servers.

## 📁 Managing your projects

When you open Cantus for the first time, the app asks you to select a folder on your computer. This folder becomes your workspace. Any files inside this directory appear in the left sidebar.

To create a new project:
1. Open the File menu.
2. Select Open Folder.
3. Choose an empty folder on your hard drive.
4. Start writing your code in the main editor window.

To stop working, simply close the window. Cantus saves your changes automatically when you close a file or stop a task.

## 🛡️ Privacy and security

Your work belongs to you. Cantus runs as a local application. It keeps your files on your computer. The engine only contacts external servers when it needs to process a request through the AI assistant. It does not upload your entire project archive unless you specifically authorize the assistant to read a specific part of your code. Your local memory store encryption keeps your history safe from unauthorized access.

## 📈 Troubleshooting common issues

If you encounter a problem, check these items first:

### The application will not open
If the app fails to start, ensure you have the latest updates for Windows installed. You may also check that your antivirus software is not blocking the installation. Occasionally, a restart of your computer clears temporary system issues that prevent new software from starting.

### The AI assistant is slow
An AI response speed depends on your internet connection. If the service feels sluggish, try closing other network-heavy applications like streaming services or large file downloads. 

### The terminal shows an error
If the terminal reports an error, look at the last few lines of the text. Often, a simple typo in a command causes this message. Use the search bar in the editor to locate the file mentioned in the error and verify your syntax.

### Updates
Cantus checks for updates automatically. If a new version is available, the app will show a notification in the top right corner of the window. You can click this notification to download and install the update immediately. Keeping the app updated ensures you have access to the latest security features and improvements.
